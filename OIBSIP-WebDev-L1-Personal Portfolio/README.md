# Personal Portfolio Website - Vedant Gadekar

A modern, responsive, and visually appealing personal portfolio website built as part of the **Oasis Infobyte Internship Program (OIBSIP) Web Development Level 1** tasks. This portfolio highlights the developer's skills, education, certifications, and key projects with interactive elements and custom CSS illustrations.

## ✨ Features

- **Responsive Design:** Mobile-first layout designed using Tailwind CSS utility classes and custom CSS media queries. It adapts seamlessly across desktops, tablets, and smartphones.
- **Smooth Navigation:** Sticky navigation bar with smooth scrolling enabled for easy section transitions.
- **Interactive Developer Scene:** A custom animated illustration of a developer's workstation built using interactive SVG assets and CSS.
- **Detailed About Me Section:**
  - Dynamic **Skills Grid** displaying technical expertise (Java EE, JavaScript, React JS, SQL & NoSQL, AWS Cloud, DevOps, GenAI & LLMs, Prompt Engineering, Data Analysis, and Unit Testing/TDD).
  - Highlights of academic qualifications.
  - List of professional certifications from Tata, Deloitte, AWS, etc.
- **Projects Portfolio:** Features deep-dive cards for major projects:
  - **Employee Management System:** Full-stack dashboard with React and Java EE APIs.
  - **Smart Student Tracker:** Educational metrics tracking tool utilizing Test-Driven Development (TDD) and React-based progress charting.
- **Contact Form:** Interactive feedback form with client-side validation.
- **Comprehensive Footer:** Includes active links to social handles (LinkedIn, GitHub, Instagram), contact details, and location.

---

## 🛠️ Technology Stack

- **HTML5:** Semantic structure and accessible DOM elements.
- **Tailwind CSS:** Utility-first styles configured directly via CDN with customized emerald color palettes and spin animations.
- **Custom CSS (`style.css`):** Custom keyframes, layout calculations, and styling for the interactive developer illustration scene.
- **Font Awesome:** Icon kit for professional social and section icons.
- **JavaScript:** Lightweight form handling and resume-view actions.

## 💻 How to Run Locally

Since this is a static frontend project, you can easily open and run it locally without installing heavy frameworks:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/VedantGadekar08/OIBSIP-.git
   cd OIBSIP-WebDev-L1-Personal Portfolio
   ```

2. **Open the project:**
   - Double-click the `index.html` file in your file explorer to open it in your default web browser.
   - Alternatively, serve it using a local server extension such as VS Code's **Live Server** or run a simple python web server command inside the directory:
     ```bash
     python -m http.server 8000
     ```
     Then navigate to `http://localhost:8000` in your browser.
