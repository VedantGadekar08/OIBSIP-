# Tribute Page - Alan Turing

A visually engaging, modern, and fully responsive tribute page dedicated to **Alan Turing**, the father of modern computer science and artificial intelligence. This project has been designed following a **"Mathematical Modernism"** aesthetic inspired by his intellectual and scientific legacy.

## Tech Stack

*   **HTML5:** Semantic layout (header, main, sections, header navigation, blockquote, footer).
*   **CSS3:** Custom styles, including smooth scroll behavior, radial-gradient math background patterns, custom timeline node markers, and card transformation hover animations.
*   **Tailwind CSS (CDN):** For modern utility styling, spacing, color variables, flexbox/grid layout, and responsive breakpoints.
*   **Google Fonts:** `Playfair Display` (Serif for display headings), `Inter` (Sans-serif for clean body copy), and `JetBrains Mono` (Monospace for labels/metadata).
*   **Material Symbols:** Google Material Icon library for clean, modern icon badges.

## Feature Checklist

*   **[x] Page Title & Tagline:** Structured hero header introducing Alan Turing as the *"Architect of the Digital Age & Hero of Bletchley Park"*.
*   **[x] Prominent Portrait:** A high-quality public domain photographic portrait from Wikimedia Commons, styled in high contrast monochrome.
*   **[x] 4-Paragraph Biography:** Comprehensive, original, and paraphrased details of Turing's academic life (the Turing Machine), wartime efforts (breaking the German Enigma code at Bletchley Park), artificial intelligence contributions (the Turing Test), and his tragic prosecution and posthumous pardoning.
*   **[x] Interactive Chronological Timeline:** An alternating styled timeline with hover animations summarizing critical dates (1912, 1936, 1939-1945, 1950, 1952-1954, 2013).
*   **[x] Quote Block:** An elegant, full-width blockquote highlighting his famous words: *"Sometimes it is the people no one can imagine anything of who do the things no one can imagine."*
*   **[x] Multiple Background Colors:** Used the cohesive slate-gray and off-white "Mathematical Slate" palette alongside dark slate and white card backdrops to structure the sections.
*   **[x] Two Font Styles:** Contrasted scholarly Serif headings (`Playfair Display`) with clean, readable Sans-serif body font (`Inter`).
*   **[x] Fully Responsive Layout:** Fully optimized for mobile, tablet, and desktop screens with custom navigation and collapsible hamburger menus.

## How to Run the Project Locally

1.  **Clone or Download the Project:**
    Ensure you have `index.html` and `styles.css` in the same directory.
    
2.  **Open in Browser:**
    Double-click the `index.html` file or open it inside any modern browser (Chrome, Safari, Firefox, Edge, etc.) to view the page.

3.  **Wartime/Bletchley Park Grid:**
    Observe the subtle mathematical grid background in the Biography section and Quote section which gives it a precise mathematical blueprint vibe!
