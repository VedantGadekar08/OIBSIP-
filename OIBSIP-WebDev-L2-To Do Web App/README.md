# To-Do Web App

A premium, interactive to-do list application that allows users to manage daily tasks. Built with modern web technologies and a focus on rich aesthetics, featuring a dynamic dark mode glassmorphism design.

## Features

- **Task Management**: Create new tasks using the input field and "Add Task" button.
- **Pending & Completed Lists**: Newly added tasks appear in the Pending list. Completed tasks move to the Completed list.
- **Task Actions**:
  - **Complete**: Toggle completion status.
  - **Edit**: Inline editing for task text.
  - **Delete**: Permanently remove tasks.
- **Task Counters**: Real-time count indicators for pending and completed tasks.
- **Timestamps**: Tasks display the time they were added and completed.
- **Persistence**: Tasks are saved to `localStorage` and persist across page reloads.
- **Empty States**: Friendly messages displayed when lists are empty.
- **Premium Design**: Modern aesthetic with glassmorphism, smooth micro-animations, and a responsive layout.

## Tech Stack

- HTML5
- CSS3 (Vanilla, custom properties, Flexbox/Grid, Glassmorphism effects)
- JavaScript (Vanilla ES6+)

## Getting Started

Simply open `index.html` in any modern web browser to start using the application. No build step or local server is required.
