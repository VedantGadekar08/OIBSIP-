# TechFlow - Modern Business Landing Page

Welcome to **TechFlow**, a clean, responsive, and modern landing page built using vanilla HTML and CSS. This project was developed as part of the **Oasis Infobyte Web Development Internship (OIBSIP) - Level 1, Task 1**.

---

## 🚀 Key Features

*   **Responsive Web Design (RWD):** Fully optimized for a wide range of devices, from ultra-wide desktops to mobile phones.
*   **Modern Aesthetics:** Features a dark-themed navigation bar and hero section accented with electric cyan (`#00d4ff`) highlights.
*   **Interactive Elements:** Dynamic micro-animations on buttons and cards using CSS transitions and transforms (e.g. lift-on-hover effects).
*   **Features Showcase:** A 6-card grid displaying company benefits and core values.
*   **Client Testimonials:** Social proof section featuring clean, styled testimonial cards.
*   **Grid and Flexbox Layouts:** Modern CSS layouts used for consistent spacing and alignment across all viewports.

## 🎨 Customization

*   **To change branding/logo:** Locate line 14 in `page.html` (`<a href="#" class="logo">TechFlow</a>`) and edit the text.
*   **To edit color schemes:** Modify the primary hex codes in `styles.css` (e.g., navigation background `#1a1a2e` and cyan color `#00d4ff`).
*   **To add sections:** Follow the semantic structure of existing HTML classes and style them using CSS layout rules.
